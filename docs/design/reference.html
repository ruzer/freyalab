1. Navegación y Apertura Directa

La aplicación elimina cualquier configuración de proyectos: abrir un archivo suelto (Vista D) oculta automáticamente el explorador lateral para dedicar el 100% de la ventana a la lectura y exportación, mientras que abrir una carpeta (Vista A) despliega el árbol lateral con filtro instantáneo (⌘P) y pestañas con indicadores visuales y textuales de cambios pendientes.

2. Herramientas Adaptadas por Archivo

La barra superior mantiene fijas las tareas universales (Abrir, Nuevo, Guardar, Exportar) y la sub-barra central muta según el formato activo: selector Editar / Dividido / Vista previa e índice para Markdown; filtros explícitos, preservación de ceros (000124) y resumen estadístico para CSV/TSV; o control de zoom y exportación directa SVG/PNG/PDF para Mermaid.

3. Confianza, Guardado y Crecimiento

En tablas filtradas (Vista B), la interfaz distingue claramente entre Guardar todo (180 filas) y Exportar 24 filas filtradas para evitar pérdidas accidentales. La conversión de documentos (Word, PDF, Excel a Markdown vía MarkItDown) vive como acción secundaria bajo el menú Abrir, manteniendo limpio el flujo cotidiano y 100% local.
