# Comprobaciones locales — 20 de octubre de 2026

## Identidad y alcance

Equipo: Apple M2 Max, 32 GiB RAM, Darwin 27.0.0, arquitectura arm64. Node utilizado para estas comprobaciones: v26.11.1; la CI está configurada para Node 24 LTS. Código en árbol de trabajo con cambios sin integrar; esta evidencia **no acredita** el commit final de publicación ni otras plataformas.

## Pruebas funcionales

Se ejecutaron seis E2E juntos y uno adicional de seguridad, todos satisfactorios sobre el build local posterior a corregir la espera de exportación PDF:

1. Renderer sin `require`/`process`; crear, editar, guardar y reabrir Markdown.
2. CSV con ceros iniciales, coma entrecomillada y campo multilínea: filtrar, editar por identificador estable, guardar y conservar valores.
3. PDF con al menos dos páginas; texto de la segunda página recuperado con PDF.js; exportar mantiene el documento modificado.
4. SVG independiente; exportar mantiene cambios pendientes.
5. HTML con fuente embebida y SVG; sin scripts ni URL de imagen remota.
6. Recuperación después de SIGKILL: documento recuperado nuevo, sin sobrescribir el original.
7. Imagen de la carpeta autorizada permitida, escape `../` bloqueado y argumento IPC inválido rechazado.

El lote de seis terminó en 8.6 s y el caso adicional en 1.7 s. Se volvió a comprobar el primer caso tras añadir capturas claro/oscuro en 1280×800 y 1440×900; pasó. Las capturas constituyen material de revisión, no una aprobación automática de fidelidad visual.

`npm run check` pasó sin errores TypeScript/Svelte en la comprobación inicial; había advertencias de la interfaz que se estaban corrigiendo. Los scripts JavaScript pasaron `node --check`. Los dos workflows se pudieron analizar como YAML con `js-yaml`.

## Observación de rendimiento

Una ejecución de `node scripts/performance.mjs` con datos sintéticos produjo:

| Medida | Resultado observado |
|---|---:|
| Inicio hasta puente disponible | 385.7 ms |
| CSV | 52 246 041 bytes, aproximadamente 49.83 MiB |
| Filas coincidentes | 151 000 |
| Apertura CSV | 1 375.7 ms |
| Filtro | 73.8 ms |
| Ordenación numérica | 203.3 ms |
| Intervalo de heartbeat del renderer, p95 | 26.1 ms |
| Intervalo máximo observado | 133.9 ms |
| Apertura de muestra de archivo sparse de 1 GiB | 38.7 ms |
| Archivo de 1 GiB editable | No; muestra de solo lectura |

La consulta de 1 GiB solo comprueba la ruta de muestra limitada; no leyó, filtró ni analizó el archivo completo. El heartbeat mide intervalos de un temporizador de 25 ms durante las operaciones, no latencia de entrada del usuario. Es una observación individual, no un benchmark estadístico ni una garantía para cualquier CSV de 50 MiB.
