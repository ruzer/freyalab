# SIM-1h · Capturas antes y después

Antes: main `6e70d549`. Después: código `23b58e7e`, capturado por la suite de integración. Mismos datos sintéticos, temas, idiomas y tamaños. Las 80 imágenes conservan sus píxeles originales; huellas y geometría resumida en [manifest.json](sim-1h-menus/manifest.json).

Markdown y pestañas no tenían menú propio en el renderer: sus capturas anteriores registran ese estado, sin afirmar qué popup pudiera ofrecer el sistema operativo. Se sustituyó solo el efecto de Mostrar en carpeta durante las pruebas funcionales; aquí no se abre Finder.
