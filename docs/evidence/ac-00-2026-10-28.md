# AC-00 · Pandoc opcional del sistema

Base de trabajo: `main` `33a5dfd`. Rama: `codex/ac-00-pandoc-opcional`.

Entrega aislada del carril C: detección y prueba de un Pandoc externo, con una conversión DOCX restringida. No incluye todavía interfaz ni IPC; los estados visibles, la selección de ruta y el botón «Probar Pandoc» se conectarán en AC-03/AC-04 sin tocar simultáneamente los componentes del carril A. Pandoc no se empaqueta ni se instala desde FreyaLab.

## Contrato para AC-03/AC-04

- `detectPandoc(chosenPath?)`: busca ejecutables absolutos en PATH y ubicaciones habituales, o valida solo la ruta elegida. Devuelve disponibilidad, ruta real, versión y licencia (`GPL-2.0-or-later`); si falta, no ejecuta conversiones y devuelve motivo y enlace a la guía oficial para el sistema.
- `pandocToDocx(executablePath, source)`: verifica la instalación y devuelve un `Buffer`; no acepta argumentos libres, filtros, motores PDF ni rutas tomadas del documento. Usa `execFile`, sin shell, con límite de 10 segundos y 64 MiB de salida, `--sandbox`, `--data-dir` temporal vacío y el lector `markdown-raw_attribute-raw_html-raw_tex-yaml_metadata_block`. Entrada por stdin y salida por stdout; ningún documento fuente se escribe al directorio temporal. El directorio se elimina incluso si la conversión falla.
- `testPandoc(executablePath)`: convierte un documento sintético UTF-8 y comprueba la firma ZIP de su DOCX; devuelve `{ok:true, bytes}` o un error comprensible.
- El YAML inicial se elimina sin el límite de 100 líneas del lector de etiquetas. Un encabezado abierto se rechaza; el lector de Pandoc también desactiva el YAML intermedio. El [manual oficial](https://pandoc.org/MANUAL.html#extension-yaml_metadata_block) explica que Pandoc admite esos bloques fuera del encabezado.
- AC-03/AC-04 deberán añadir campos explícitos para los metadatos, la bibliografía autorizada y los estilos. Este módulo aún no activa `--citeproc`, índices ni plantillas; no se abre un canal de argumentos arbitrarios para anticiparlos.

## Casos P4

| Caso | Control verificable | Resultado protegido local |
| --- | --- | --- |
| YAML con `bibliography` externo | El título canario aparece en el DOCX del control con `--sandbox --citeproc`. | No aparece; incluye encabezado de más de 100 líneas y YAML intermedio. |
| Bloque `{=openxml}` | Aparecen elementos `w:fldChar` / `w:instrText` reales. | Ninguno; se inspecciona el XML dentro del DOCX. |
| Imágenes por ruta | El control incorpora la imagen absoluta. | La ruta externa y la relativa no se incorporan; una imagen `data:` autorizada sí. |
| Filtros | El filtro Lua real crea su archivo canario cuando se pasa por CLI. | El YAML `filters` / `lua-filter` no lo ejecuta; la lista fija nunca incluye esos argumentos. |
| Imagen HTTP | El servidor local recibe una petición de Node y una petición del control Pandoc 3.10.2, compilado con HTTP. | La conversión protegida recibe cero peticiones y no incluye medios remotos, con ambas versiones. |

**Distinción del control HTTP:** Pandoc Homebrew 3.12.1 responde al control sin sandbox con `pandoc was compiled without HTTP support`; cero peticiones con ese binario no demuestra por sí solo la eficacia de `--sandbox` para HTTP. Pandoc **3.10.2 sí admite HTTP**: el control sin sandbox registra una petición y la conversión restringida cero, con lo que esa frontera sí se verifica localmente. La suite conserva la aserción protegida de cero para ambos y publica la distinción. El [manual oficial](https://pandoc.org/MANUAL.html#a-note-on-security) limita el alcance de `--sandbox` a lectores y escritores; por eso esta invocación fija excluye filtros y motores PDF.

**Límite del control bibliográfico:** el control deliberadamente inseguro activa `--citeproc`, mientras que el módulo inicial todavía no lo activa. El resultado real protegido, junto a las unitarias que comprueban el YAML eliminado y el lector fijo, cubre la invocación actual; no demuestra por separado la eficacia de cada defensa con citas activadas. AC-03 debe repetir este caso sobre su invocación final con `--citeproc` y bibliografía autorizada antes de dar por cubierto ese flujo.
