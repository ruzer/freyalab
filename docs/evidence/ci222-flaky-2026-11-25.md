### Cómo repetir las sondas

Se conservan dos parches diagnósticos, **no aplicados a la entrega**: [rojo](ci222-reproduccion-roja.patch) y [verde](ci222-reproduccion-verde.patch). Cada uno se aplica por separado en un worktree desechable de la base indicada, con sus dependencias y build actualizados. No se aplican uno encima de otro ni sobre el head final.

```sh
git apply /ruta/ci222-reproduccion-roja.patch
npm run build
FREYALAB_CI222_CSV_PROBE=1 FREYALAB_CI222_PROJECT_PROBE=1 \
  npx playwright test tests/e2e/analysis-sections.spec.ts tests/e2e/chart-trend.spec.ts \
  tests/e2e/csv-text.spec.ts tests/e2e/project-subset-analysis.spec.ts \
  --project=csv --grep 'el menú exporta datos exactos|degenerados explican|el encabezado rechazado|Analizar ejecuta los cambios guardados' \
  --workers=1 --retries=0 --reporter=list
```

Repetir con `--workers=2`. Para verde, aplicar solo el parche verde a otra copia limpia de la misma base y añadir `FREYALAB_CI222_CSV_RELEASE_BEFORE_READ=1` al entorno. Los parches conservan todos los datos, assertions y plazos originales. Intervenciones:

1. Mover el puntero fuera tras el hover solo para Ingreso/Y.
2. Retener la primera petición real de página de UI y encolar junto a ella la lectura auxiliar: se observa la cancelación real, no se simula su error.
3. Retener la respuesta real de `project:create`, después de publicar su evento, durante dos cuadros de renderizado; observar el Enter real.

**Diferencia deliberada entre sondas:** en rojo las gates CSV/proyecto se liberan por la acción prematura del ayudante. El arreglo evita esa acción; esperar su llegada dejaría bloqueada la propia sonda. En verde el controlador libera las respuestas retenidas de forma explícita y el ayudante espera las filas/el cierre. En Proyecto, un `keyup` sintético solo libera la gate diagnóstica (por eso su JSON tiene `keydown:null`); el Enter posterior sobre «Añadir fuente» sigue siendo real. No se pretende presentar ambos calendarios como una prueba A/B idéntica. El caso del puntero sí mantiene exactamente la misma perturbación en rojo y verde. Las repeticiones definitivas no contienen gates, flags ni modificaciones temporales de IPC.
