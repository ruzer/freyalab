# FreyaLab
Electron + TypeScript estricto + Svelte. Mantener la distribución del render en docs/design/reference.html. Todos los recursos se incluyen localmente; sin telemetría ni cargas remotas. Única excepción: la comprobación de actualizaciones (APP-04), una petición HTTPS a `api.github.com` desde el proceso principal que la persona hace o activa en Ajustes; sin identificadores, sin descarga ni instalación automática.
No mezclar funciones de importación Office/PDF, OCR, multimedia, SQL o archivos de GB con la alfa.
Validar IPC, aislar renderer y vista de exportación, conservar valores CSV y originales ante errores. No declarar una muestra como archivo completo.
Por bloque: prueba roja antes del cambio, implementación mínima y pruebas enfocadas hasta verde; registra comandos y resultados según [CONTRIBUTING](CONTRIBUTING.md#comprobaciones-locales). Al cierre de la rama de integración: npm run check, npm test completo (incluido CSV), npm run test:e2e completo y npm run build. La CI completa de las cuatro plataformas, las pruebas del paquete y las comprobaciones críticas deben pasar sobre el head final. Mientras la CI califica un SHA congelado, el desarrollo puede continuar en otra rama y worktree sin modificar ese head; su verde no se transfiere a otro SHA. Cada entrega: rama codex/, PR revisable, evidencia verificable. CI faltante bloquea publicación; no confundir build con prueba del paquete o instalador.
