# Icono de FreyaLab

Imagen elegida y proporcionada por el usuario el 21 de octubre de 2026. El original de 1254 × 1254 se conserva sin cambios en `docs/design/freya-icon-original.png`.

`icon.png` es la copia de 1024 × 1024 para distribución y las marcas de la interfaz. Conserva la composición, los colores y el fondo blanco del original. Se obtiene con una reducción proporcional, sin generar otra ilustración.

Electron Builder convierte este PNG a ICNS para macOS e ICO para Windows; Linux utiliza PNG. El proceso principal y la interfaz usan el mismo recurso, incluido localmente por electron-vite. No requiere dependencias nuevas. El generador provisional de la F se retiró para evitar sobrescribir la imagen elegida.
